# PicoProjects

MicroPython projects for a Raspberry Pi Pico W with a Waveshare 2.13-inch
e-paper display.

## Projects

- [Astronomy](astronomy/README.md) — Displays moon phases, sunrise and sunset
  times, and live astronomy events.
- [Weather](weather/README.md) — Displays current weather conditions and a five-day
  forecast using OpenWeather data.
